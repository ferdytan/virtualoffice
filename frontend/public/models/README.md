# 3D Models Directory

Folder ini disiapkan untuk menyimpan aset 3D model eksternal berformat `.glb` atau `.gltf` jika ingin menggunakan custom 3D model:
- `nara.glb`
- `velocia.glb`
- `scout.glb`
- `office_scene.glb`

Jika aset .glb tidak diletakkan di folder ini, aplikasi secara otomatis merender representasi 3D Avatar Chibi & Kantor Claymorphic procedural Three.js bawaan dengan material matte, pencahayaan soft shadow, dan warna solid akurat.
